## 一、SDD - 软件设计文档

### 1. 知识库构建模块

#### 1.1 PDF解析 (`src/knowledge/pdf_parser.py`)
- 复用参考项目的 `pdf_parsing.py` 和 `pdf_mineru.py` 逻辑
- 支持两种解析方式：Docling本地解析、MinerU云端解析
- 输入：`data/knowledge_base/course_pdfs/` 下的PDF文件
- 输出：解析后的Markdown文本

#### 1.2 文本分块 (`src/knowledge/text_splitter.py`)
- 复用参考项目的 `text_splitter.py`
- 按Token数分块，支持表格特殊处理
- 每个chunk附带元数据（来源课程名、章节、页码）
- 输出：`data/processed/course_chunks/` 下的JSON文件

#### 1.3 向量化入库 (`src/knowledge/ingestion.py`)
- 复用参考项目的 `ingestion.py`
- 支持FAISS向量索引和BM25索引双通道
- Embedding模型支持DashScope text-embedding-v1 / OpenAI text-embedding-3-large

#### 1.4 项目精华提炼 (`src/knowledge/project_extractor.py`) [核心新模块]
- 用LLM读取项目源码和文档，提炼结构化信息
- 输出格式（Pydantic Schema）：
  ```python
  class ProjectExtract(BaseModel):
      project_name: str          # 项目名称
      description: str           # 项目描述（2-3句话）
      tech_stack: List[str]      # 技术栈列表
      highlights: List[str]      # 项目亮点（技术亮点、优化手段等）
      role_contribution: str     # 个人角色与贡献
      key_metrics: str           # 可量化的成果指标（如有）
  ```
- 支持批量处理多个项目目录
- 输出：`data/processed/project_extracts/` 下的JSON文件
- 提炼后需人工review，修改JSON即可

### 2. 检索模块

#### 2.1 检索器 (`src/retrieval/retriever.py`)
- 参考 `RAG-cy/src/retrieval.py`，但简化：去掉按公司名检索的逻辑
- 改为按知识类型（课程/项目/面试题）分类检索
- 支持向量检索、BM25检索、混合检索三种模式

#### 2.2 重排序 (`src/retrieval/reranker.py`)
- 直接复用参考项目的 `reranking.py`

### 3. Agent模块 (LangGraph) - 双模式路由架构

#### 3.1 意图分类 (`src/agent/intent.py`)

Agent 通过意图识别节点将用户请求路由到两种处理模式：

```python
class IntentType(str, Enum):
    QUICK_RESPONSE = "quick_response"     # 快速反应模式
    DEEP_THINKING = "deep_thinking"       # 深思熟虑模式
    CHITCHAT = "chitchat"                 # 闲聊/兜底

# 意图分类规则：
# - quick_response: 面试题问答、知识点查询、项目信息查询等单轮问答
# - deep_thinking:  简历生成、简历优化、针对岗位调整等需要多步推理的任务
# - chitchat:       无法识别意图的兜底对话
```

意图识别通过 LLM 结构化输出实现，输入用户消息，输出 IntentType + 关键实体提取（如岗位名称、技术关键词等）。

#### 3.2 Agent状态 (`src/agent/state.py`)
```python
class AgentState(TypedDict):
    messages: List[BaseMessage]       # 对话消息列表
    user_input: str                   # 用户原始输入
    intent: str                       # 意图分类结果：quick_response / deep_thinking / chitchat
    extracted_entities: Dict          # 意图识别时提取的实体（岗位名、技术词等）
    has_job_requirement: bool         # 是否有岗位要求
    retrieved_knowledge: str          # 检索到的知识上下文
    retrieved_projects: str           # 检索到的项目精华
    resume_draft: str                 # 简历草稿（仅deep_thinking模式）
    resume_final: str                 # 最终简历（仅deep_thinking模式）
    final_response: str               # 最终回复（通用）
    step: str                         # 当前执行步骤
```

#### 3.3 Agent工具 (`src/agent/tools.py`)
- `search_knowledge(query: str, category: str = None) -> str`：从知识库检索课程知识点，支持按category过滤
- `search_projects(query: str) -> str`：从知识库检索项目精华
- `generate_resume(knowledge: str, projects: str, job_requirement: str = None) -> str`：调用LLM生成简历（仅deep_thinking模式使用）
- `answer_question(question: str, context: str) -> str`：基于检索上下文直接回答问题（quick_response模式使用）

#### 3.4 LangGraph图 (`src/agent/graph.py`) - 双模式路由

```
                    用户输入
                       |
                       v
              +--[意图识别]--+
              |   classify_intent  |
              |              |
         quick_response   deep_thinking    chitchat
              |              |                |
              v              v                v
      [快速检索路径]    [深思熟虑路径]      [闲聊兜底]
              |              |                |
    单次检索 -> 直接回答   多步检索 -> 草稿 -> 优化   直接回复
              |              |                |
              v              v                v
           最终回复        最终简历          最终回复
```

**快速反应模式 (quick_response)** 流程：
1. 意图识别 + 实体提取（如识别到"RAG"、"Faiss"等技术关键词）
2. 单次检索：根据意图直接调用 `search_knowledge` 或 `search_projects`
3. 直接回答：调用 `answer_question` 基于检索结果生成回答
4. 输出最终回复

适用场景：
- "RAG的核心流程是什么？"
- "Faiss和Milvus有什么区别？"
- "简历生成Agent项目用了什么技术栈？"
- "LangGraph的条件路由怎么用？"

**深思熟虑模式 (deep_thinking)** 流程：
1. 意图识别 + 实体提取（如识别到岗位JD、目标公司等）
2. 多轮检索：并行调用 `search_knowledge` + `search_projects`，收集全面素材
3. 生成简历草稿：调用 `generate_resume`，综合所有素材
4. 优化润色：如有岗位要求，针对性调整措辞和重点
5. 输出最终简历

适用场景：
- "帮我生成一份简历"
- "针对这个岗位优化我的简历：[JD]"
- "帮我准备一份AI Agent方向的简历"

**闲聊兜底模式 (chitchat)** 流程：
1. 意图识别判定为闲聊
2. 直接以Agent角色身份回复，引导用户提出具体需求

#### 3.5 Agent Prompt (`src/agent/prompts.py`)
- **意图识别Prompt**：分类用户输入为 quick_response / deep_thinking / chitchat，同时提取关键实体
- **快速回答Prompt**：基于检索结果简洁准确回答问题
- **简历生成Prompt**：指导LLM组织简历结构（个人信息、技能栈、项目经历、教育背景）
- **简历优化Prompt**：根据岗位要求针对性优化简历内容和措辞
- **闲聊Prompt**：定义Agent角色，引导用户

### 4. 数据模型 (`src/schemas/`)

#### 4.1 知识条目模型
```python
class KnowledgeChunk(BaseModel):
    chunk_id: str
    source: str              # 来源课程名
    category: str            # 分类：course / project / interview
    content: str
    metadata: Dict[str, Any] # 页码、章节等
```

#### 4.2 简历输出模型
```python
class Resume(BaseModel):
    name: str
    title: str                          # 求职意向
    summary: str                        # 个人简介
    skills: List[str]                   # 技能列表
    projects: List[ProjectInResume]     # 项目经历
    education: List[EducationItem]      # 教育背景
    additional: str                     # 其他信息
```

### 5. Streamlit UI (`app_streamlit.py`)

参考 `RAG-cy/app_streamlit.py` 的风格，主要功能：
- 知识库管理：上传PDF、触发知识处理流程
- 项目管理：查看/编辑已提炼的项目精华
- 简历生成：输入岗位要求（可选），一键生成简历
- 简历预览：Markdown渲染简历，支持导出

### 6. 多模型支持 (`src/api_client.py`)

参考 `RAG-cy/src/api_requests.py` 的 `APIProcessor` 设计：
- 支持 DashScope（通义千问）、OpenAI、Gemini 三种后端
- 通过 `config.py` 中的配置切换默认模型
- 统一接口：`send_message()` + 结构化输出支持

## 五、与参考项目的主要差异

| 维度 | 参考项目 (RAG-cy) | 本项目 (ResumeAgent) |
|------|-------------------|---------------------|
| 目标 | 财报问答 | 简历生成 |
| Agent | 无（纯Pipeline） | LangGraph Agent |
| 检索维度 | 按公司名检索 | 按知识类型检索 |
| 知识来源 | 结构化财报PDF | 课程PDF + 项目源码 + 面试题 |
| 输出 | 结构化答案(JSON) | 创造性简历文本 + 快速知识问答 |
| Agent路由 | 无 | 双模式路由（quick_response / deep_thinking） |
| 新增模块 | 无 | project_extractor.py, agent/intent.py, agent/* |
